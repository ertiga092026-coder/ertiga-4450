# Ertiga Manager
Plain static PWA. No data, secrets or keys in this repo.
Deploy: GitHub → Settings → Pages → Deploy from branch `main` / root. Then follow the Google setup in the app's Settings page: create an OAuth Client ID (Web application, no secret) with your Pages URL as authorised origin, paste it in Settings, Connect.
Your data lives only in your browser and in your Google Drive folder "Ertiga Manager Data". Never commit data files.
